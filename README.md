# DUET 2027 Journey Tracker

A personal web application for tracking and visualizing preparation progress for the DUET admission test.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Routing:** React Router
- **UI & Styling:** Tailwind CSS, shadcn/ui, Lucide React
- **State Management:** Zustand
- **Validation:** Zod
- **Date Handling:** date-fns
- **Charts & Visualizations:** Recharts
- **Storage:** Dexie + IndexedDB (Local-First)
- **Testing:** Vitest, React Testing Library

## Commands

- `npm run dev` - Start development server (http://localhost:5173)
- `npm run build` - Build production bundle
- `npm run preview` - Preview production bundle
- `npm run test` - Run unit tests with Vitest
- `npm run typecheck` - Run TypeScript compiler checks
